description: A project that explores heart-rate variability (HRV) features extracted from ECG segments to classify psychological stress using machine learning. Using a dataset of 50+ participants exposed to spider video clips, ECG signals are filtered, R-peaks are detected with the Pan-Tompkins algorithm, and time- and frequency-domain HRV features are computed. Features are standardized and classified using a logistic regression model, with leave-one-subject-out cross-validation used to evaluate performance. This project provides experience in ECG signal processing, HRV feature extraction, artifact removal, and applying machine learning to physiological data. All implementation and analysis were done in MATLAB.
